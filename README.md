# 📚 Study Planner - 스터디 플래너

오늘의 목표를 정하고, 공부 시간을 기록하며, D-Day를 관리하는 웹 기반 스터디 플래너입니다.

## ✨ 주요 기능

### 1️⃣ 오늘의 정보
- **현재 날짜 및 요일 표시** - 매일 새로운 마음으로 시작
- **D-Day 관리** - 중요한 날까지의 날짜 카운트다운
  - 추가/수정/삭제 가능
  - 실시간 D-Day 계산 (D-100, D-1, D-Day, D+1 등)

### 2️⃣ 오늘의 계획
- **과목 관리** - 자유롭게 과목 추가/삭제
- **할일 목록** - 각 과목별 세부 작업 항목
  - 완료 여부 체크박스
  - 진행률 표시 (완료: x/y)
  - 직관적인 UI로 시각적 피드백

### 3️⃣ 공부 시간 기록
- **시간대별 공부 현황** - 30분 단위 시간표
- **과목별 색상 구분** - 한눈에 보는 공부 분포
- **빠른 기록** - 표를 클릭하여 직접 추가
- **총 공부시간 계산** - 누적 시간 자동 계산

## 📱 사용 방법

### D-Day 추가
1. 헤더의 "+ 추가" 버튼 클릭
2. 이름과 날짜 입력
3. "저장" 클릭

### 과목 및 할일 추가
1. "오늘의 계획" 섹션에서 "+ 과목 추가" 버튼 클릭
2. 과목명 입력
3. 과목 카드에서 할일 입력 후 추가

### 공부 시간 기록
**방법 1: 빠른 추가**
- 시간표에서 해당 셀 클릭

**방법 2: 선택으로 추가**
1. 시간과 과목 선택
2. "기록 추가" 클릭

**기록 삭제**
- 시간표의 표시된 셀 클릭

## 📝 API 엔드포인트

### 데이터 조회
- `GET /api/data` - 전체 데이터
- `GET /api/today` - 오늘 날짜

### D-Day
- `POST /api/dday/add` - D-Day 추가
- `POST /api/dday/update` - D-Day 수정
- `POST /api/dday/delete` - D-Day 삭제

### 과목
- `POST /api/plan/subject/add` - 과목 추가
- `POST /api/plan/subject/delete` - 과목 삭제

### 할일
- `POST /api/plan/task/add` - 할일 추가
- `POST /api/plan/task/update` - 할일 수정
- `POST /api/plan/task/delete` - 할일 삭제

### 공부 기록
- `POST /api/study-record/add` - 기록 추가
- `POST /api/study-record/delete` - 기록 삭제

## 💡 팁

- **다짐 입력** - 상단의 동기부여 문구를 입력하면 매일 새롭게 시작
- **색상 구분** - 8가지 과목까지 각각 다른 색상으로 구분
- **시간 단위** - 30분 단위로 세분화하여 정확한 기록 가능
